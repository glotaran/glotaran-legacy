Glotaran 1.6.0 has the features of Glotaran 1.5.3, rebuilt on Apache NetBeans Platform 31 and Java 25. Glotaran 1.5 ran on NetBeans Platform 8.0.2 and Java 8. Analyses still run in R with the TIMP package, as in 1.5.

For new work, we recommend [pyglotaran](https://github.com/glotaran/pyglotaran). New releases of this application appear on the [GitHub Releases page](https://github.com/glotaran/glotaran-legacy/releases).

## New

- **Java is included.** The Windows installer, the Linux packages and the macOS disk images contain a Java 25 runtime (Eclipse Temurin), so you do not need to install Java.
- **Installers for each system:** a Windows installer, `.deb` and `.rpm` packages for Linux, and disk images for Apple silicon and Intel Macs.
- **Runs next to 1.5.x.** Glotaran 1.6 keeps its settings in its own folder (`.glotaran/1.6`). Settings from 1.5 are not copied.
- Glotaran 1.6 checks for updates at `https://glotaran.org/suc/1.6/stable/`.

## Fixed

- Opening a dataset whose data file was moved or deleted now shows an error that names the missing file and suggests *Cache dataset to project folder*. Before, this failed with a NullPointerException.

## Updating from 1.5.x

Tools | Plugins in Glotaran 1.5.x does not update to 1.6. Install 1.6 with one of the downloads below. It can be installed next to 1.5.x; remove 1.5.x when you no longer need it.

| System | File |
|---|---|
| Windows, 64-bit | `Glotaran-1.6.0-windows-x64-setup.exe` |
| Linux: Debian, Ubuntu and derivatives | `Glotaran-1.6.0-linux-amd64.deb` |
| Linux: Fedora, openSUSE and other RPM-based systems | `Glotaran-1.6.0-linux-x86_64.rpm` |
| macOS, Apple silicon (M1 and later) | `Glotaran-1.6.0-macos-aarch64.dmg` |

`SHA256SUMS` contains the checksums of all files. Check a download with `sha256sum -c SHA256SUMS --ignore-missing`. `Glotaran-1.6.0-autoupdate-site.zip` holds the modules for the update server; you do not need it to install Glotaran.

## Installing

**Windows:** run the installer. It needs administrator rights and installs to `C:\Program Files\Glotaran`. The installer is not code-signed, so Windows SmartScreen may show "Windows protected your PC"; click *More info*, then *Run anyway*.

**Linux:** install the package with your package manager, for example
`sudo apt install ./Glotaran-1.6.0-linux-amd64.deb` or
`sudo dnf install ./Glotaran-1.6.0-linux-x86_64.rpm`.
Glotaran then appears in the application menu and can be started from a terminal with `glotaran`.

**macOS:** open the disk image and drag Glotaran to Applications. The app is not signed or notarized by Apple, so macOS refuses to open it the first time. After that first attempt, open *System Settings > Privacy & Security* and click *Open Anyway*, or run this once in Terminal:
`xattr -dr com.apple.quarantine /Applications/Glotaran.app`

**Generic zip:** unzip it and run `bin/glotaran` (Linux, macOS) or `bin\glotaran64.exe` (Windows). It needs Java 21 or newer and was tested with Java 25. If Glotaran does not find Java, start it with `--jdkhome <path to your Java installation>`.

## Requirements for analyses

As in 1.5, fitting a model requires R with the TIMP and Rserve packages. Install both in R with:

```r
install.packages(c("TIMP", "Rserve"))
```

Start Rserve in R before running an analysis in Glotaran:

```r
library(Rserve)
Rserve(args = "--no-save")
```

## Known issues

- The installers and disk images are not code-signed (see *Installing*).
- During the release build, each installer and disk image is installed and started on GitHub's Windows, Linux and macOS (Apple silicon and Intel) machines. The macOS disk images have not been tested by hand on a Mac. Reports from Mac users are especially welcome.
- On Windows, the program file `glotaran64.exe` shows the NetBeans icon. The Start menu and desktop shortcuts show the Glotaran icon.

## Feedback

Report problems at https://github.com/glotaran/glotaran-legacy/issues. Please include your operating system, the file you downloaded, and Glotaran's log file:

- Windows: `%USERPROFILE%\.glotaran\1.6\var\log\messages.log`
- Linux: `~/.glotaran/1.6/var/log/messages.log`
- macOS: `~/Library/Application Support/glotaran/1.6/var/log/messages.log`

The same folder is shown as *User directory* in *Help > About*.

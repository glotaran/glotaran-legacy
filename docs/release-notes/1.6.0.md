Glotaran 1.6.0 runs on current Windows, macOS and Linux computers. The installers include everything Glotaran needs to start, including Java, so you do not have to install Java yourself. Analyses still run in R with the TIMP package and give the same results as in Glotaran 1.5.3.

New releases of Glotaran 1.x appear on the [Glotaran Releases page](https://github.com/glotaran/glotaran-legacy/releases). 

_Note that for new work, we recommend [pyglotaran](https://github.com/glotaran/pyglotaran), the Python-based spiritual successor to Glotaran._

## What's new

- **Easier installation.** There is an installer for Windows, a disk image for Macs with Apple silicon and one for Intel Macs, and installation packages for Linux. Each of them includes Java.
- **Works next to Glotaran 1.5.** You can keep Glotaran 1.5 installed while you try 1.6. The two versions keep their settings separately, so settings you made in 1.5 do not appear in 1.6.
- **Clearer message when a data file is missing.** If you open a dataset whose data file was moved or deleted, Glotaran now tells you which file is missing and suggests *Cache dataset to project folder*. Before, it showed a technical error message.
- **Updated foundation.** Glotaran now runs on Java 25 and Apache NetBeans Platform 31. Glotaran 1.5 used Java 8 and NetBeans Platform 8.0.2.

## Which file do I need?

| Your computer | Download |
|---|---|
| Windows | `Glotaran-1.6.0-windows-x64-setup.exe` |
| Mac with Apple silicon (M1, M2, M3 or later) | `Glotaran-1.6.0-macos-aarch64.dmg` |
| Mac with an Intel processor | `Glotaran-1.6.0-macos-x64.dmg` |
| Linux: Ubuntu, Debian, Linux Mint | `Glotaran-1.6.0-linux-amd64.deb` |
| Linux: Fedora, openSUSE | `Glotaran-1.6.0-linux-x86_64.rpm` |

To find out which Mac you have, open the Apple menu and choose *About This Mac*. If it shows *Chip* with an Apple M-series name, you have Apple silicon. If it shows *Processor* with an Intel name, you have an Intel Mac.

You do not need the other files. `Glotaran-1.6.0-generic.zip` is for computers that already have Java 21 or newer installed and contains no installer. `SHA256SUMS` and `Glotaran-1.6.0-autoupdate-site.zip` are for checking downloads and for the Glotaran update server.

## Installing

**Windows:** double-click the downloaded file and follow the steps. You need administrator rights. Windows may show the message "Windows protected your PC", because the installer is not signed with a certificate. Click *More info*, then *Run anyway*. After the installation, start Glotaran from the Start menu.

**Mac:** double-click the downloaded file, then drag Glotaran to the Applications folder. The first time you open Glotaran, macOS blocks it because the app is not signed by Apple. To open it anyway:

1. Open Glotaran once and close the message that appears.
2. Open *System Settings* and go to *Privacy & Security*.
3. Scroll down, click *Open Anyway* next to the message about Glotaran, and confirm.

You only need to do this once.

**Linux:** double-click the downloaded file to open it in your software installer, then click *Install*. Glotaran then appears in your applications menu.

## Before your first analysis

Glotaran uses the free program R with the TIMP package to fit models. Set this up once:

1. Download and install R from [cran.r-project.org](https://cran.r-project.org).
2. Open R, type the following line and press Enter. If R asks you to choose a download location (mirror), pick one near you.

   ```r
   install.packages(c("TIMP", "Rserve"))
   ```

Each time before you run an analysis in Glotaran, open R, type the following two lines and press Enter after each:

```r
library(Rserve)
Rserve(args = "--no-save")
```

Tested on Windows 11 with R 4.6.1, TIMP 1.13.6 and Rserve 1.8-19.1.

## Coming from Glotaran 1.5

Glotaran 1.5 does not update itself to 1.6. Download and install 1.6 as described above. You can uninstall Glotaran 1.5 when you no longer need it.

## Known issues

- The installers are not signed, so Windows and macOS show a warning the first time (see *Installing*).
- The Mac version was tested automatically, but not yet by a person on a Mac. If you use a Mac, please let us know whether Glotaran works for you.

## Problems and questions

Report problems on the [Glotaran issues page](https://github.com/glotaran/glotaran-legacy/issues) (you need a free GitHub account). Please tell us which computer and which file you use. It also helps if you include Glotaran's log: in Glotaran, choose *View > Glotaran Log*, copy the text and paste it into your report.

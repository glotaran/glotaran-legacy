Glotaran 1.7.0 installs and starts R for you. On your first analysis, Glotaran downloads R with the TIMP and Rserve packages, installs them in your user folder without administrator rights, and starts and stops R itself. You no longer need to install R or start Rserve before an analysis. If you already use your own R with TIMP and Rserve, you can keep using it as in Glotaran 1.6.

New releases of Glotaran 1.x appear on the [Glotaran Releases page](https://github.com/glotaran/glotaran-legacy/releases).

_Note that for new work, we recommend [pyglotaran](https://github.com/glotaran/pyglotaran), the Python-based spiritual successor to Glotaran._

## What's new

- **R is installed for you.** On the first analysis or simulation, Glotaran downloads R 4.4.3 and Rserve from [conda-forge](https://conda-forge.org) and TIMP from the [TIMP releases on GitHub](https://github.com/glotaran/TIMP/releases) (about 260 to 310 MB, depending on your computer, and about 1.2 GB on disk) and installs them in its own folder. A progress bar in the status bar shows the installation; you can cancel it there. Later analyses start R in a few seconds.
- **No Rserve to start.** Glotaran starts R when an analysis needs it and stops it when you close Glotaran. It uses a free port on your computer, so it does not get in the way of an Rserve you run yourself.
- **Your own R stays possible.** If Glotaran finds an R installation or a running Rserve on your computer, it asks once which one to use. You can change the choice later (see *Settings* below).
- **Works next to Glotaran 1.6.** Glotaran 1.7 keeps its settings, and the R it installs, separately from Glotaran 1.6.

## Fixed

- On Linux and Macs, Glotaran logged an error at startup when it was started from the applications menu or from Finder, because it had no folder for its temporary files (cache). The cache is now in `~/.cache/glotaran/1.7` on Linux, `~/Library/Caches/glotaran/1.7` on a Mac and `%LOCALAPPDATA%\glotaran\Cache\1.7` on Windows.

## Which file do I need?

| Your computer | Download |
|---|---|
| Windows | `Glotaran-1.7.0-windows-x64-setup.exe` |
| Mac with Apple silicon (M1, M2, M3 or later) | `Glotaran-1.7.0-macos-aarch64.dmg` |
| Mac with an Intel processor | `Glotaran-1.7.0-macos-x64.dmg` |
| Linux: Ubuntu, Debian, Linux Mint | `Glotaran-1.7.0-linux-amd64.deb` |
| Linux: Fedora, openSUSE | `Glotaran-1.7.0-linux-x86_64.rpm` |

To find out which Mac you have, open the Apple menu and choose *About This Mac*. If it shows *Chip* with an Apple M-series name, you have Apple silicon. If it shows *Processor* with an Intel name, you have an Intel Mac.

You do not need the other files. `Glotaran-1.7.0-generic.zip` is for computers that already have Java 21 or newer installed and contains no installer; with it, Glotaran also downloads the small program it uses to install R (micromamba). `SHA256SUMS` and `Glotaran-1.7.0-autoupdate-site.zip` are for checking downloads and for the Glotaran update server.

## Installing

**Windows:** double-click the downloaded file and follow the steps. You need administrator rights. Windows may show the message "Windows protected your PC", because the installer is not signed with a certificate. Click *More info*, then *Run anyway*. After the installation, start Glotaran from the Start menu.

**Mac:** double-click the downloaded file, then drag Glotaran to the Applications folder. The first time you open Glotaran, macOS blocks it because the app is not signed by Apple. To open it anyway:

1. Open Glotaran once and close the message that appears.
2. Open *System Settings* and go to *Privacy & Security*.
3. Scroll down, click *Open Anyway* next to the message about Glotaran, and confirm.

You only need to do this once.

**Linux:** double-click the downloaded file to open it in your software installer, then click *Install*. Glotaran then appears in your applications menu.

## Your first analysis

Your computer needs an internet connection for the first analysis.

- If Glotaran finds no R on your computer, it installs R when you start the first analysis. A message tells you that R is being installed, and the analysis starts when the installation is complete. This takes a few minutes, depending on your connection.
- If Glotaran finds an R installation or a running Rserve, it asks which R to use:
  - *Download and install R for Glotaran* installs R as described above.
  - *Use my own R installation* works as in Glotaran 1.6: install TIMP and Rserve in your R with `install.packages(c("TIMP", "Rserve"))`, and before each analysis start Rserve in R with `library(Rserve)` and `Rserve(args = "--no-save")`.
  - *Cancel* stops the analysis; Glotaran asks again at the next analysis.

The R that Glotaran installs is used only by Glotaran. It does not change your own R installation and does not use the packages in your own R library.

Tested on Windows 11, Debian Linux, a Mac with Apple silicon and an Intel Mac, with the R that Glotaran installs: R 4.4.3, TIMP 1.13.6 and Rserve 1.8-14.

## Settings

Choose *Tools > Options*, then *Glotaran* and the *R runtime* tab. There you can:

- switch between *Installed by Glotaran* and *My own R (Rserve on localhost:6311)*;
- see the status, the versions of R, TIMP and Rserve, the folder and the size on disk;
- *Reinstall* or *Remove* the R that Glotaran installed, and *Open install log* if an installation failed.

Glotaran installs R in the folder `.glotaran/1.7/r-runtime` in your home folder (on a Mac, `.glotaran` is a hidden folder; press Cmd+Shift+. in Finder to show it). Uninstalling Glotaran does not delete this folder; use *Remove* in the settings first, or delete the folder yourself.

## Coming from Glotaran 1.6

Glotaran 1.6 does not update itself to 1.7. Download and install 1.7 as described above. You can uninstall Glotaran 1.6 when you no longer need it. Your own R installation keeps working with Glotaran 1.6 and, if you choose it, with Glotaran 1.7.

## Known issues

- The installers are not signed, so Windows and macOS show a warning the first time (see *Installing*).
- If Glotaran is closed abnormally (for example when it crashes or is ended in the Task Manager), the R it started keeps running until you end it yourself or restart your computer.
- The installation of R has not been tested behind a proxy server. The download uses the proxy set in the environment variables `HTTPS_PROXY` and `HTTP_PROXY`.
- If you use conda, `conda env list` also shows the R environment that Glotaran installed.

## Problems and questions

Report problems on the [Glotaran issues page](https://github.com/glotaran/glotaran-legacy/issues) (you need a free GitHub account). Please tell us which computer and which file you use. It also helps if you include Glotaran's log: in Glotaran, choose *View > Glotaran Log*, copy the text and paste it into your report. If the installation of R failed, also include the install log (*Open install log* in the settings).

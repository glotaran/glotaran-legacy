Glotaran 1.5.3 is the last release of Glotaran 1.5, and the last release that runs on Java 8 and NetBeans Platform 8.0.2. Glotaran 1.6 moves to Java 25 and NetBeans Platform 31.

For new work, we recommend [pyglotaran](https://github.com/glotaran/pyglotaran). New releases of this application appear on the [GitHub Releases page](https://github.com/glotaran/glotaran-legacy/releases).

## New

- A notice at startup points to pyglotaran and to new Glotaran releases. Tick "Do not show this notice at startup" to hide it. Help | pyglotaran and Glotaran Releases shows it again.
- Load data from Labmonkey data folders.
- Specify a measured IRF (proof of concept).
- When you add datasets, Glotaran opens the folder you used last.
- Glotaran checks for updates at the new, secure address `https://glotaran.org/suc/1.5/stable/`.

## Fixed

- CSV loader preview when rows or columns are skipped.
- Exporting comma-separated files from the export tab (#29).
- An extra line in SVG exports.
- Plots not updating after switching between linear and lin-log axes.
- Opening FLIM images.
- Crosshair values in combined plots of data, fit and residuals.
- Outlier correction.
- The progress output in the result view, including fits that stop after 0 iterations.
- The error "Requested name contains invalid characters".

## Updating from 1.5.1

In Glotaran 1.5.1, open Tools | Plugins, click Check for Updates on the Updates tab, install all updates, and restart Glotaran. Alternatively, download the ZIP below and install it next to or in place of 1.5.1.

## Requirements

- Java 8. The download does not include Java.
- R with the TIMP and Rserve packages, to run analyses. Install both in R with:

  ```r
  install.packages(c("TIMP", "Rserve"))
  ```

  Start Rserve in R before running an analysis in Glotaran:

  ```r
  library(Rserve)
  Rserve(args = "--no-save")
  ```

Tested on Windows 11 with Java 8 (Temurin 8.0.492), R 4.6.1, TIMP 1.13.6 and Rserve 1.8-19.1.

## Installation

Unzip `glotaran-app-1.5.3.zip` and run:

- Windows 64-bit: `bin/glotaran64.exe`
- Windows 32-bit: `bin/glotaran.exe`
- Linux and macOS: `bin/glotaran`

Glotaran 1.5.3 shares its settings with other 1.5 versions. They are stored in `.glotaran/1.5` in your home folder, or `Library/Application Support/glotaran/1.5` on macOS.

To check the download, compare it with `glotaran-app-1.5.3.zip.sha256`:

```sh
sha256sum -c glotaran-app-1.5.3.zip.sha256
```

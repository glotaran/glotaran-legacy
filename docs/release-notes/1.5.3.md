Glotaran 1.5.3 is the final maintenance release of Glotaran on NetBeans Platform 8.0.2 and Java 8.

For new work, Glotaran 1.x has been superseded by [pyglotaran](https://github.com/glotaran/pyglotaran). New releases of this application are published on the [GitHub Releases page](https://github.com/glotaran/glotaran-legacy/releases).

Version 1.5.2 was never officially released. Snapshot builds labelled 1.5.2 were handed to some users; 1.5.3 contains everything in those builds.

## Changes since 1.5.1

- A notice at startup points to pyglotaran and to the GitHub Releases page. Tick "Do not show this notice at startup" to hide it; Help | pyglotaran and Glotaran Releases shows it again.
- New data loader for Labmonkey data folders.
- Proof-of-concept specification of a measured IRF.
- The last used data file location is remembered when adding datasets.
- Fixed: CSV loader preview with skipped rows or columns.
- Fixed: export of comma-separated files from the export tab (#29).
- Fixed: extra line in SVG export.
- Fixed: plots not updating after switching between linear and lin-log axes.
- Fixed: opening FLIM images.
- Fixed: crosshair values in combined plots (data, fit and residuals).
- Fixed: outlier correction.
- Fixed: parsing of the nls progress output in the result view, including optimizations with 0 iterations.
- Fixed: "Requested name contains invalid characters" error.
- Updated third-party libraries, including snakeyaml 1.26.

## Requirements

- Java 8 runtime. The ZIP does not include Java.
- R with the TIMP and Rserve packages, for running analyses. Install both from CRAN in R:

  ```r
  install.packages(c("TIMP", "Rserve"))
  ```

Glotaran connects to Rserve on the local machine at the default port (6311) but does not start it. Start Rserve in R before running an analysis:

```r
library(Rserve)
Rserve(args = "--no-save")
```

The Rserve connection and a TIMP fit were checked on Windows 11 with Temurin JDK 8.0.492, R 4.6.1, TIMP 1.13.6 and Rserve 1.8-19.1.

## Installation

Unzip `glotaran-app-1.5.3.zip` and run `bin/glotaran64.exe` (64-bit Windows), `bin/glotaran.exe` (32-bit Windows) or `bin/glotaran` (Linux and macOS). Settings are stored in `.glotaran/1.5` in the home directory (`Library/Application Support/glotaran/1.5` on macOS), which is shared with other 1.5.x versions.

Verify the download against `glotaran-app-1.5.3.zip.sha256`:

```sh
sha256sum -c glotaran-app-1.5.3.zip.sha256
```
